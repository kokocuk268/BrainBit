# BrainFocus - Спецификация проекта

## 1. Описание проекта

**Название проекта:** BrainFocus
**Тип проекта:** Android-приложение
**Основная функциональность:** Нейрофидбэк-игра, которая подключается к гарнитуре BrainBit EEG, анализирует концентрацию пользователя по данным энцефалограммы и использует её для динамического изменения сложности игры — чем выше концентрация, тем легче игра (препятствия падают медленнее), чем ниже концентрация, тем сложнее (препятствия падают быстрее).

## 2. Технологический стек

### Фреймворк и язык
- **Язык:** Kotlin 1.9.x
- **Минимальная версия SDK:** 21 (Android 5.1)
- **Целевая версия SDK:** 34 (Android 14)
- **Версия для компиляции:** 34

### Основные библиотеки и зависимости
- **NeuroSDK 2:** 1.0.6.34 — интеграция с гарнитурой BrainBit
- **Kotlin Coroutines:** 1.7.3 — асинхронное программирование
- **Lifecycle ViewModel:** 2.6.2 — архитектура MVVM
- **Material Design 3:** 1.10.0 — компоненты интерфейса
- **AndroidX Core KTX:** 1.12.0 — расширения Kotlin

### Управление состоянием
- Kotlin StateFlow и SharedFlow для реактивных потоков данных
- ViewModel для управления состоянием интерфейса
- Паттерн Repository для слоя данных

### Архитектурный паттерн
- **MVVM** (Model-View-ViewModel)
- Чистая архитектура с разделением ответственности:
  - **Слой UI:** Activity, Fragment, ViewModel
  - **Доменный слой:** Бизнес-логика
  - **Слой данных:** Интеграция с BrainBit SDK, репозитории

## 3. Список функций

### Подключение устройства
- Сканирование BLE-устройств BrainBit
- Выбор устройства из списка найденных
- Управление состоянием подключения (подключение, подключено, отключено)
- Обработка разрешений для Bluetooth и геолокации

### Обработка данных ЭЭГ
- Получение данных ЭЭГ в реальном времени (4 канала: T3, T4, O1, O2)
- Извлечение бета-ритма (13-30 Гц) для расчёта концентрации
- Нормализация сигнала (диапазон 0.0 - 1.0)
- Сглаживание скользящим средним для стабильности

### Игровая механика
- Отрисовка на SurfaceView с частотой 60 FPS
- Управление персонажем наклоном устройства (акселерометр)
- Падающие препятствия с обнаружением столкновений
- Динамическая сложность на основе концентрации:
  - Высокая концентрация (0.7-1.0): Медленное падение объектов
  - Средняя концентрация (0.3-0.7): Обычная скорость
  - Низкая концентрация (0.0-0.3): Быстрое падение объектов
- Подсчёт очков (время выживания)
- Конец игры при столкновении

### Пользовательский интерфейс
- **Экран подключения:** Сканирование устройства, статус подключения, кнопка запуска, режим тестирования
- **Игровой экран:** Игровое поле, счёт, индикатор концентрации, кнопка паузы
- **Экран результатов:** Финальный счёт, средняя концентрация, кнопки повтора

## 4. Дизайн интерфейса

### Общий стиль
- Material Design 3 с тёмной темой
- Футуристическая/нейротехнологичная эстетика
- Чистый, минималистичный интерфейс с фокусом на геймплей

### Цветовая схема
- **Основной цвет:** Тёмно-фиолетовый (#6200EE)
- **Дополнительный цвет:** Бирюзовый (#03DAC6)
- **Фон:** Тёмно-серый (#121212)
- **Поверхность:** Приподнятый тёмный (#1E1E1E)
- **Индикатор концентрации:** Зелёный (высокая) → Жёлтый (средняя) → Красный (низкая)

### Подход к компоновке
- Single Activity с навигацией через Fragment
- Экран подключения как начальный фрагмент
- Полноэкранный игровой вид
- Модальный диалог результатов при завершении игры

### Типографика
- Семейство шрифтов sans-serif
- Крупный, читаемый дисплей счёта
- Чёткая иконография для кнопок
